# Sumber ringkasan ulasan

Disemak pada **26 Oktober 2026** daripada [profil Google Maps Jitra2Stay](https://goo.gl/maps/pjnMbwm5Pk2QqPeP8). Nama homestay, alamat No. 49 Jalan Indah 7, telefon dan pautan website sepadan dengan rumah ini.

| Nama awam | Kandungan sumber yang diringkaskan |
| --- | --- |
| Fakhrurrazi Yusoff | Menyatakan penginapan tujuh hari mereka selesa. |
| Hamidi Hamid | Memuji ruang rumah, kebersihan dan tekanan air. |

Website memaparkan parafrasa BM/EN yang dilabel **Ringkasan ulasan Google**, dengan atribusi dan pautan sumber. Tiada tanda petikan, bintang, jumlah ulasan, tarikh ulasan tepat atau structured data rating ditambah. Tarikh semakan ialah tarikh sumber dibaca, bukan tarikh tetamu menginap. Pautan menuju profil tempat kerana pautan ulasan individu tidak tersedia dalam sumber yang dibaca.

Reka bentuk mengikuti prinsip foto sebenar, maklumat ringkas dan bukti sosial daripada [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill). Tipografi Lora digunakan untuk tajuk sahaja; lesen dan sumber font terdapat dalam `src/fonts/`.
