# Display font

Lora Regular, Latin subset, is hosted locally for headings. Body text and form controls use the system font. The single 21 KB WOFF2 uses `font-display: swap` with Georgia as a fallback.

- [UI UX Pro Max typography reference](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/src/ui-ux-pro-max/data/typography.csv): Lora appears in the natural, calm serif option.
- [Google Fonts stylesheet](https://fonts.googleapis.com/css2?family=Lora:wght@400&display=swap), retrieved 26 October 2026.
- [Unmodified WOFF2 source](https://fonts.gstatic.com/s/lora/v37/0QI6MX1D_JOuGQbT0gvTJPa787weuxJBkq0.woff2).
- [Upstream licence](https://github.com/google/fonts/blob/main/ofl/lora/OFL.txt); its copy is included as `OFL-Lora.txt` and published alongside the font.

The build copies only the font and licence. No request to Google Fonts is made by the website.
